Saved progress

Idle Call Center saves your progress automatically. Game progress and settings are stored locally on the device. Deleting the app may remove saved game progress.

Restore a purchase

Open the main menu and select Restore Purchases. Make sure the device is signed in with the Apple Account that originally purchased the Full Game Unlock.

Full Game Unlock

The Full Game Unlock is a one-time, non-consumable purchase. It is not a subscription.

Game Center

Idle Call Center supports Apple Game Center for the global final-score leaderboard. Make sure you are signed in to Game Center if leaderboard features are unavailable.
